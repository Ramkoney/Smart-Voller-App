# 🏐 Volleyball Game Score Tracker

This is a web-based application for recording and managing volleyball game scores.
It allows users to input match details, team scores,
official names, and upload relevant documents like fixtures.

---

## 📋 Features

- Input **match date** and upload a **PDF fixture**.
- Record details for **Team A** and **Team B**.
- Specify the **pool number** and **team category** (Male/Female).
- Enter scores for **three sets**.
- Log names of **officials**: Score Keeper, Referees, and Line Judges.
- Submit match data.
- User **Sign Out** functionality.

---

## 🖥️ Technologies Used

- **HTML**
- **CSS3**
- **JavaScript** (linked via `app.js`)
- Background image support for styling.
